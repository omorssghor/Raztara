RAZTARA Privacy & ব্যবহারবিধি

1. Chat

কোনো User-এর সাথে Chat খুললে আগের মেসেজ দেখা যাবে। নতুন মেসেজ নিচে যোগ হবে। আপনি নিজে scroll করলে উপরে বা নিচে যেতে পারবেন; chat নিজে থেকে অযথা নড়বে না।

2. Voice, Video ও Audio Call

Chat header-এর Audio বা Video button চাপলে কল শুরু হবে। Incoming call এলে Accept বা Reject করা যাবে।

3. Voice Message

নিচের 🎙️ button চেপে voice record করুন। রেকর্ড শেষ হলে আগে Preview হবে। Preview দেখে Send চাপলে মেসেজ যাবে।

4. Camera, Video, Picture ও File

নিচের + button চাপুন। Camera, Video, File অথবা Picture নির্বাচন করুন। নির্বাচিত ছবি/ভিডিও/ফাইল আগে Preview হবে; Send চাপার পরেই Chat-এ যাবে।

5. Profile Detail

User যে তথ্য সবার জন্য অনুমতি দিয়েছেন শুধু সেই তথ্য অন্য User দেখতে পারবে। Private করা তথ্য অন্য User দেখতে পারবে না। অন্য User আপনার Profile তথ্য Edit করতে পারবে না।

6. Background

Chat Menu → Background থেকে নিজের পছন্দের ছবি নির্বাচন করে Chat background পরিবর্তন করা যাবে।

7. Gallery

Gallery-তে দুই User-এর Chat-এর ছবি, ভিডিও, voice ও file পাওয়া যাবে। প্রয়োজন অনুযায়ী Save বা Delete করার সুবিধা থাকবে যেখানে অনুমতি দেওয়া আছে।

8. Block User

কাউকে Block করলে তার সাথে যোগাযোগ ও তার Chat/Profile আপনার কাছে বন্ধ থাকবে। Index → Settings → Blocked Users থেকে Unblock করলে আবার স্বাভাবিকভাবে দেখা ও ব্যবহার করা যাবে।

9. Privacy

Profile Privacy settings থেকে কোন তথ্য অন্যরা দেখতে পারবে তা নিয়ন্ত্রণ করুন। Public করলে অনুমোদিত তথ্য দেখা যাবে; Private করলে তা গোপন থাকবে।

10. ভাষা

RAZTARA-এর ভাষা শুধু Index → Settings থেকে পরিবর্তন করতে হবে। সেখানে ভাষা পরিবর্তন করলে অ্যাপের সমর্থিত জায়গাগুলোতে একই ভাষা স্বয়ংক্রিয়ভাবে ব্যবহার হবে।

11. Logout

Menu বা Settings থেকে Logout করলে বর্তমান account থেকে বের হয়ে Login page-এ ফিরে যাবেন। আবার ব্যবহার করতে নিজের account দিয়ে Login করতে হবে।

12. নিরাপত্তা

নিজের password, OTP বা account access অন্য কারও সাথে শেয়ার করবেন না। অপরিচিত User বা সন্দেহজনক file/link ব্যবহারে সতর্ক থাকুন।
